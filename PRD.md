# 材料样板管理系统 - 产品需求文档

## 1. 项目概述

### 1.1 项目背景

配合样板中心建设进行的样板输入管理系统。其目标在于入库后现场管理人员可通过扫码快速查看样板详情，同时支持二维码标签生成和打印。系统还支持权限控制，保护敏感信息不被未授权访问。

### 1.2 项目目标

- 提供便捷的样板信息录入和管理功能
- 支持二维码标签生成和打印
- 支持通过扫码快速查看样板详情
- 实现权限控制，游客通过输入邀请码才能查看敏感信息，将信息进行初步分类。

### 1.3 目标用户

- 普通用户、设计师（扫码查看样板材料详情）
- 现场管理人员（手机端通过拍照完成登入）

## 3. 非功能需求

### 3.1 性能要求

- 页面加载时间 < 3 秒
- 操作响应时间 < 1 秒
- 支持同时 100 用户在线

### 3.2 兼容性要求

- 支持 Chrome、Firefox、Edge 等现代浏览器
- 支持移动端响应式布局
- 支持扫码应用内打开

### 3.3 安全性要求

- 用户数据隔离（每个用户只能看到自己的数据）
- 图片存储权限控制
- 邀请码每日更新

## 4. 技术架构

### 4.1 前端

- **技术栈**: 原生 HTML5 + CSS3 + JavaScript (ES6+)
- **架构**: 单页应用（SPA），Category → Samples → Labels 三层视图
- **导航**: 左侧固定侧边栏（桌面端）/ 顶部水平栏（移动端）
- **UI 框架**: 无，使用自定义 CSS
- **二维码**: 自定义 Canvas 绘制 / qrcode-generator 库

### 4.2 后端

- **数据库**: Supabase (PostgreSQL)
- **认证**: Supabase Auth
- **存储**: Supabase Storage
- **API**: Supabase REST API

### 4.3 开发环境

- **服务器**: Node.js HTTP Server
- **端口**: 3000

## 6. 界面设计

### 6.1 页面结构

1. **登录页面**: 居中卡片式登录表单，展示当日邀请码
2. **类别列表页**: 卡片网格布局，展示所有类别（含品牌标签、样本数量、集采标签）；桌面端卡片正方形，品牌以蓝色小标签置于 meta 行
3. **样板列表页**: 卡片网格布局，展示类别下所有样板。卡片分为图片区（thumbnail 加载，点击可放大查看原图）和信息区（样板名称+型号同行、编号独立行、集采范围标签行，底部操作按钮行）
4. **标签打印页**: 4列网格布局，展示所有样板的打印标签，每张标签顶部显示类别名称（半透明白色小字）和样板名称
5. **信息页**: 页面视图展示邀请码（日期与"有效"徽章同行）和字段可见性配置（无返回按钮，header 与类别列表一致）
6. **扫码详情页**: 独立页面（无导航），卡片式布局，分为"基础信息"（始终显示类别/型号/品牌/集采信息）和"扩展信息"（邀请码验证后显示）

### 6.2 导航方式

- **桌面端 (>768px)**: 左侧固定侧边栏（200px），包含用户信息、类别、信息、退出
- **移动端 (≤768px)**: 顶部水平导航栏，隐藏用户信息

### 6.3 设计风格

- 锤子手机系统极简风格，以白色和蓝色为主色调
- 卡片式设计，统一的圆角和阴影，所有的圆角控制在3px
- 响应式布局，适配桌面和移动端
- 类别卡片桌面端正方形布局（aspect-ratio: 1），品牌以蓝色小标签嵌入 meta 行代替独立行
- 扫码详情页采用手机优先卡片式布局，字段分组为"基础信息"和"扩展信息"两个独立卡片，字体简洁紧凑
- 邀请码输入区域采用全宽虚线按钮，触控面积大，适合手机操作
- 样板卡片信息区布局：名称与型号同行（弹性布局，名称超长省略），编号独立行（等宽字体），集采范围标签独立行
- 图片裁切弹窗：全屏深色背景（#000），顶部 header 栏包含 ×（取消重拍）和 ✓（确认裁切）两个圆形按钮，中部为图片 + 半透明裁切框（含 8 方向白色手柄可拖拽调整），底部为"取消/确认"按钮栏（裁切框锁定后出现）
- 图片查看器：全屏半透明深色遮罩（rgba(0,0,0,0.85)），原图居中展示（max-width 92vw, max-height 92vh），点击遮罩关闭，无关闭按钮。仅样板详情页图片可点击放大，列表页无此功能

### 6.4 关键交互

- 集采联动：类别设为非集采时，该类别下所有样品的集采标签和范围内外固定显示"非集采·范围外"
- 品牌联动：编辑类别品牌后，该类别下所有样板的品牌字段自动同步
- 全选切换：第一次点击全选，再次点击取消全选
- 侧边栏高亮：当前视图对应的导航项高亮显示
- 可见性管理：「信息」页展示全部8个标签字段（始终显示）和5个可配置字段，后者的可见性通过三状态胶囊(显示/邀请/敏感)切换，默认"邀请"，设置持久化到数据库
- 集采范围切换：录入/编辑样板时使用两状态胶囊（范围内/范围外）替代复选框，非集采类别下胶囊置灰不可编辑
- 信息页布局：分为"标签内容"（8个始终显示的标签字段）和"扫码可见性"（5个可配置的三状态胶囊）两大区域。信息页无返回按钮，header 与类别列表风格一致
- 类别编辑弹窗：类别名称与品牌并排一行（无 label），集采使用两状态胶囊（非集采/集采），集采时间使用年+月下拉框并排，非集采时隐藏时间行
- 标签排版：打印标签顶部增加一行类别名称（半透明白色小字），位于样板名称上方
- 扫码页可见性：公开字段（类别/型号/品牌）+ 被设为"显示"的字段 + 是否集采/集采时间/范围内外 → 无需邀请码始终显示；被设为"邀请"的字段 → 需输入邀请码；被设为"敏感"的字段 → 永不显示
- 型号重复检测：保存样板时自动检查所有样板中是否已存在相同型号，若重复则 toast 提示并阻止保存
- 图片双路压缩：上传时同时生成 600px 全尺寸图（详情查看用）和 200px 缩略图（列表渲染用），保证列表秒开，详情清晰
- 图片裁切流程：拍照/选择文件后进入全屏裁切弹窗 → 拖拽移动 + 8 方向手柄调整裁选区 → 点击 ✓ 锁定 → 底部出现"取消/确认" → 确认后按选区截取原图 → 应用到表单预览区
- 图片点击放大：仅样板详情页图片可点击弹出全屏遮罩显示原图，点击遮罩关闭；列表页图片无放大交互
- 样板卡片信息区：样板名称与型号同行显示（弹性布局，flex-shrink），编号独占一行（独立字重），集采范围标签在底部

| 二维码扫描兼容性    | 部分设备无法识别 | 使用标准 QR 码格式，测试主流扫码应用 |
| 图片存储空间不足    | 上传失败         | 图片压缩、定期清理                   |
| 浏览器打印差异      | 标签格式错乱     | 使用 @media print 优化打印样式       |

## 9. 附录

### 9.1 术语表

- **样板**: 建筑材料实物样品
- **标签**: 包含样板信息和二维码的打印卡片
- **邀请码**: 当日有效的权限验证码
- **演示模式**: 无需后端即可体验功能的模式
- **集采**: 集中采购，由类别决定是否属于集采项目
- **范围内/外**: 样板是否在集采采购时间范围内，录入时使用两状态胶囊切换
- **扫码可见性**: 样板字段（规格/颜色/材质/描述/图片）的二维码展示权限，支持三状态（显示/邀请/敏感）
- **缩略图**: 上传图片时自动生成的 200px 小图，用于列表快速渲染
- **裁切**: 拍照后在全屏弹窗中通过拖拽/手柄调整选区，按选区截取原图
