# 材料样板管理系统

一个基于 Web 的材料样板管理系统，用于管理建筑材料样板的录入、查看和打印标签。

## 项目结构

```
easycod/
├── src/                    # 源代码目录
│   ├── css/               # 样式文件
│   │   └── style.css      # 全局样式
│   └── js/                # JavaScript 文件
│       ├── app.js         # 主应用逻辑
│       └── detail.js      # 样板详情页逻辑
├── index.html             # 主页面
├── sample-detail.html     # 样板详情页（扫码查看）
├── README.md                 # 产品需求文档
├── server.js              # 开发服务器
└── supabase-setup.sql     # Supabase 数据库初始化脚本
```

## 技术栈

- **前端**: 原生 HTML5 + CSS3 + JavaScript (ES6+)
- **后端**: Supabase (Auth + Database + Storage)
- **二维码**: qrcode-generator

## 功能特性

1. **类别管理**: 创建、编辑、删除材料类别。编辑弹窗紧凑布局：名称与品牌并排（无 label，placeholder 提示），集采使用两状态胶囊切换，集采时间使用年+月下拉框。增删改查双向同步 Supabase 数据库
2. **样板录入**: 拍照上传、自动压缩（600px 全尺寸 + 200px 缩略图双路输出）、全屏裁切弹窗（拖拽+8方向手柄调整）、型号重复检测、placeholder 紧凑表单、两状态胶囊切换集采范围
3. **字段可见性管理**: 5 个样板字段（规格/颜色/材质/描述/图片）支持三状态控制（显示/邀请/敏感），默认"邀请"，持久化到数据库。"显示"字段始终可见，"邀请"字段需验证码后可见，"敏感"字段永不显示
4. **标签打印**: 生成和打印样板标签（含二维码），标签顶部显示类别名称
5. **权限验证**: 当日邀请码验证，控制敏感信息展示。Supabase Auth 登录（邮箱密码，首次自动注册）
6. **扫码查看**: 扫描二维码查看样板详情，手机优先卡片式布局，公开信息（类别/型号/品牌/集采字段）始终显示，邀请字段需验证后显示

## 快速开始

### 环境要求

- Node.js (用于开发服务器)
- Supabase 账号

### 配置步骤

1. **创建 Supabase 项目**
   - 登录 [Supabase](https://supabase.com/)
   - 创建新项目
   - 在项目设置中获取 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`

2. **配置数据库**
   - 在 Supabase SQL 编辑器中执行 `supabase-setup.sql`
   - 创建必要的表和存储桶

3. **更新配置**
   - 修改 `src/js/app.js` 和 `src/js/detail.js` 中的配置：
     ```javascript
     const SUPABASE_URL = "你的 Supabase URL";
     const SUPABASE_ANON_KEY = "你的 Anon Key";
     ```

4. **启动开发服务器**

   ```bash
   node server.js
   ```

5. **访问应用**
   - 打开浏览器访问 `http://localhost:3000`

## 演示模式

系统支持演示模式，无需真实登录即可体验功能：

- 在 `src/js/app.js` 中设置 `DEMO_MODE = true`
- 演示模式使用模拟数据，不会连接真实数据库

## 使用说明

### 登录

- 在演示模式下，输入任意邮箱和密码即可登录
- 在生产模式下，使用 Supabase 账号登录

### 类别管理

- 点击"新建类别"创建新类别
- 点击类别卡片查看样板列表。桌面端卡片为正方形，品牌以蓝色小标签置于 meta 行
- 编辑弹窗布局紧凑：类别名称与品牌并排一行（placeholder 替代 label），集采使用胶囊切换，集采时间使用年+月下拉框

### 样板录入

- 选择类别后点击"录入样板"
- 拍照或选择图片上传 → 进入全屏裁切弹窗：拖拽移动裁选区、8方向手柄调整大小 → ✓ 锁定 → 确认后应用到表单
- 图片自动生成 600px 全尺寸图（详情查看）+ 200px 缩略图（列表渲染），列表加载更快
- 填写品牌、型号和编号信息。型号不能重复，已存在相同型号时会有提示

### 样板列表

- 卡片信息区布局：样板名称 + 型号同行，编号独立一行，集采范围标签在底部
- 详情页图片可点击放大查看原图（全屏遮罩弹窗）

### 标签打印

- 点击样板的"标签页"按钮查看单个标签（顶部显示类别名称）
- 点击"打印所有标签"批量打印（每张标签顶部显示类别名称）

### 权限验证

- 部分敏感信息需要验证邀请码
- 邀请码每日自动生成，当天有效
- 通过侧边栏「信息」页可查看邀请码并配置扫码可见性（日期与"有效"徽章同行显示，无返回按钮）
- 生产模式使用 Supabase Auth，首次登录自动注册

### 删除数据

- 在 Web 端删除类别或样板后，数据库同步删除，不会叠加数据

### 字段可见性

- 5 个样板字段（规格/颜色/材质/描述/图片）默认"邀请"（需邀请码）
- "显示"字段无需邀请码始终可见
- "敏感"字段不论是否输入邀请码均不显示
- 是否集采、集采时间、范围内外始终显示，无需邀请码
- 在「信息」页点击胶囊切换状态，设置持久化到数据库和 localStorage 不丢失

## 注意事项

1. 首次使用需要配置 Supabase 项目
2. 图片上传需要配置存储桶权限
3. 建议在演示模式下先熟悉功能
4. 生产环境需要配置适当的安全规则
